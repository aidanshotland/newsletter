### 🔐 Show HN: OneCLI – Vault for AI Agents in Rust
OneCLI is an open-source credential vault and gateway, built in Rust, designed to secure API keys for AI agents. It transparently injects real credentials when agents make HTTP calls through its proxy, using placeholder keys on the agent side. This mechanism allows AI agents to access services without directly handling sensitive secrets, mitigating significant security risks associated with giving agents raw API access.
